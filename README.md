# DXF Viewer Library

Легковесная JavaScript библиотека для просмотра и анализа DXF файлов в браузере с акцентом на строительные чертежи и армирование.

## 🎯 Цели проекта

Создать собственную библиотеку для:
- Просмотра DXF файлов из Lira-SAPR
- Работы со схемами армирования
- Измерений и анализа чертежей
- Экспорта в различные форматы

## ⚡ Ключевые особенности

- **Легковесная**: ~50-100KB (минимальная сборка)
- **Специализированная**: Оптимизирована для строительных чертежей
- **Модульная**: Используйте только нужные компоненты
- **Производительная**: Рендеринг 10,000+ объектов без лагов
- **Расширяемая**: Простое API для добавления функций

## 📦 Возможности

### Основные функции
- ✅ Загрузка и парсинг DXF файлов (R12-R2018+)
- ✅ Рендеринг всех базовых примитивов (LINE, POLYLINE, CIRCLE, ARC, TEXT, MTEXT, HATCH)
- ✅ Управление слоями (показать/скрыть, фильтры)
- ✅ Навигация (zoom, pan, fit to screen)
- ✅ Работа с текстом (поиск, копирование, экспорт)
- ✅ Заливки и штриховки с паттернами
- ✅ Измерения (расстояния, углы, площади)
- ✅ Экспорт (PNG, JPG, SVG, JSON)

### Специализированные функции
- ✅ Распознавание элементов армирования
- ✅ Анализ схем армирования
- ✅ Построение огибающих
- ✅ Извлечение спецификаций

## 🚀 Быстрый старт

```html
<!DOCTYPE html>
<html>
<head>
  <script src="dxf-viewer.min.js"></script>
</head>
<body>
  <div id="viewer-container"></div>
  
  <script>
    const viewer = new DXFViewer({
      container: '#viewer-container',
      width: 1200,
      height: 800
    });
    
    // Загрузка файла
    viewer.loadFile('drawing.dxf').then(() => {
      console.log('DXF loaded!');
      viewer.fitToScreen();
    });
  </script>
</body>
</html>
```

## 🛠️ Технологии

- **Язык**: JavaScript (ES6+)
- **Сборка**: Rollup / Webpack
- **Тесты**: Jest
- **Рендеринг**: Canvas API
- **Опционально**: TypeScript для типизации

## 📋 Требования

- Современный браузер с поддержкой:
  - ES6+
  - Canvas API
  - Web Workers (для больших файлов)
  - File API
